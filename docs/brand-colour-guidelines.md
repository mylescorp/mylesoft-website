# MylesCorp Technologies Brand Colour Guidelines

## 60-30-10 Foundation

Every landing page and product surface should follow this split:

- 60% Navy `#1A395B` for dominant structure: navbars, hero backgrounds, sidebars, social proof sections, and footers.
- 30% White/Ice `#FFFFFF` / `#EEF2F8` for breathing room: content areas, cards, tables, and alternate section backgrounds.
- 10% Gold `#C79639` for action and emphasis: primary buttons, thin rules, icons, focus states, and small badges.

Gold is intentionally rare. If it is used everywhere, it stops behaving like a premium action colour.

## Core Tokens

| Token | Hex | Use |
| --- | --- | --- |
| Navy | `#1A395B` | Primary structural colour |
| White | `#FFFFFF` | Main content surfaces and text on navy |
| Ice | `#EEF2F8` | Neutral surface, alternate bands, cards, table rows |
| Gold | `#C79639` | CTAs, accents, section rules, icons, focus rings |
| Gold Hover | `#A67C2E` | Hover state for gold buttons |
| Light Blue | `#C7D7EF` | Secondary hierarchy on navy |
| Muted Blue | `#95A9CC` | Inactive and secondary UI |
| Dark Grey | `#212121` | Body text |
| Medium Grey | `#545454` | Subtitles and helper text |
| Error Red | `#D32F2F` | Destructive actions and error states only |

## Landing Page Rules

| Element | Colour Rule |
| --- | --- |
| Top navbar | Navy background, white links, gold CTA only |
| Hero section | Navy background, white headline, light blue sub-headline |
| Primary CTA | Gold background with navy text |
| Secondary CTA | White outline with white text on navy |
| Section dividers | Thin gold rules |
| Body sections | Alternate white and ice |
| Section headings | Navy on white or ice |
| Body text | Dark grey, never pure black |
| Feature cards | White or ice with gold icon/accent |
| Featured pricing card | Navy background, white text, gold badge |
| Testimonial section | Navy background, white quote text, light blue role text |
| Footer | Navy background, muted blue links, gold divider |

## SaaS Product UI Rules

| Component | Colour Rule |
| --- | --- |
| Sidebar | Navy background |
| Sidebar active item | Gold left border with ice tint |
| Sidebar inactive item | Light blue text, muted blue icon |
| Top header | White background with navy border-bottom |
| Main content background | Ice or very light grey |
| Primary button | Gold background with navy text |
| Primary hover | Gold hover `#A67C2E` |
| Secondary button | Navy background with white text |
| Destructive button | Error red `#D32F2F` |
| Input focus | Gold border or focus ring |
| Table header | Navy background with white text |
| Badge success/active | Ice background with navy text |
| Modal overlay | `rgba(26,57,91,0.6)` |
| Progress bar | Gold fill on ice track |

## Critical Rules

1. Never use gold as a large-area background.
2. Never use gold text on white or ice.
3. Use light blue only as secondary hierarchy on navy.
4. Use muted blue only for inactive or secondary UI.
5. Use dark grey for body text everywhere.
6. Use red for errors and destructive actions, not brand colours.
7. Use ice instead of generic grey for neutral surfaces.
